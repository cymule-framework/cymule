# Governance

Cymule is maintained by repository maintainers using review-based consensus.

Semantic compatibility is conservative: a change to effect identity, scope
commit, causal admission, authority, replay, or migration behavior requires a
new semantic specification version. Experimental compiler and plugin features
may evolve independently when their version domain is explicit.

Maintainers may reject changes that enlarge the trusted core without a concrete
semantic requirement or that bind the framework to a particular infrastructure
product.
